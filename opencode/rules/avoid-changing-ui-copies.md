# UI Copy Restrictions

## Strict UI Copy Lock

- **DO NOT** modify, update, or rephrase any UI text, labels, button copy, tooltips, error messages, or user-facing strings automatically.
- If a task requires modifying UI copy:
  1. STOP before making the edit.
  2. Ask for explicit user confirmation, providing the exact proposed text changes.
  3. Wait for approval before editing the target file or localization bundle.
